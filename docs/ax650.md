# AX650 SDK 部署指南

将爱芯元智 AX650 SDK 部署到 `/soc/` 并配置环境变量

---

## 前置条件

- 目标平台：AX650 SoC (Linux x86_64 或 ARM64)
- 安装路径：`/soc/`

---

## 部署步骤

### 1. 安装 SDK 到 /soc/

[SDK](https://github.com/AXERA-TECH/ax650n_bsp_sdk.git)

```bash
# 方式 1: 解压官方 SDK 包
unzip ax650n_bsp_sdk-1.45.0_p39.zip -C /

# 方式 2: 从其他位置复制
sudo cp -r /path/to/ax650-bsp-sdk/msp/out /soc/

# 验证目录结构
ls /soc/lib/           # 应包含 libax_*.so
ls /soc/soc/include/   # 应包含 ax_*.h
```

---

### 2. 配置环境变量

编辑 `~/.bashrc`：

```bash
# === AX SDK Paths ===
export CMAKE_PREFIX_PATH="/soc:$CMAKE_PREFIX_PATH"
export CMAKE_INCLUDE_PATH="/soc/soc/include:$CMAKE_INCLUDE_PATH"
export CMAKE_LIBRARY_PATH="/soc/lib:$CMAKE_LIBRARY_PATH"
export LD_LIBRARY_PATH="/soc/lib:$LD_LIBRARY_PATH"
```

或者使用一键配置：

```bash
cat >> ~/.bashrc << 'EOF'

# === AX SDK Paths (Added by deployment) ===
export CMAKE_PREFIX_PATH="/soc:$CMAKE_PREFIX_PATH"
export CMAKE_INCLUDE_PATH="/soc/soc/include:$CMAKE_INCLUDE_PATH"
export CMAKE_LIBRARY_PATH="/soc/lib:$CMAKE_LIBRARY_PATH"
export LD_LIBRARY_PATH="/soc/lib:$LD_LIBRARY_PATH"
EOF
```

使配置生效：

```bash
source ~/.bashrc
```

---

### 3. 验证安装

```bash
# 检查库文件
ls /soc/lib/libax_*.so | wc -l    # 应输出 ~47

# 检查头文件
ls /soc/soc/include/ax_*.h | wc -l  # 应输出 ~55

# 检查环境变量
echo $CMAKE_LIBRARY_PATH          # 应包含 /soc/lib
echo $LD_LIBRARY_PATH             # 应包含 /soc/lib
```

---

### 4. CMake 配置

在项目 `CMakeLists.txt` 中添加：

```cmake
# AX SDK 路径
set(AX_SDK_DIR "/soc")

include_directories(${AX_SDK_DIR}/soc/include)
link_directories(${AX_SDK_DIR}/lib)

target_link_libraries(your_target PRIVATE ax_sys ax_ivps ax_ive ...)
```

## 故障排查

### 问题：找不到共享库

```bash
error while loading shared libraries: libax_sys.so: cannot open shared object file
```

**解决**：检查 `LD_LIBRARY_PATH`

```bash
echo $LD_LIBRARY_PATH | grep -o /soc/lib
# 如果没有输出，重新 source ~/.bashrc
```

---

### 问题：CMake 找不到头文件

```bash
fatal error: ax_sys_api.h: No such file or directory
```

**解决**：检查 `CMAKE_INCLUDE_PATH`

```bash
cmake --find-package -DNAME=ax_sys -DCOMPILER_ID=GNU -DLANGUAGE=C -DMODE=EXIST
```

---

### 问题：SDK 目录不存在

```bash
ls: cannot access '/soc': No such file or directory
```

**解决**：重新部署 SDK 到 `/soc/`

## 目录结构

```
/soc/
├── lib/                    # 47 个动态链接库
│   ├── libax_sys.so        # 系统核心
│   ├── libax_ivps.so       # 图像处理
│   ├── libax_ive.so        # CV 加速
│   ├── libax_engine.so     # AI 推理
│   └── ...
└── soc/
    ├── include/            # 55 个头文件
    │   ├── ax_sys_api.h
    │   ├── ax_ivps_api.h
    │   └── ...
    └── lib/                # 静态链接库 (.a)
```

---

## 系统级配置（可选）

如果需要全局访问（所有用户），创建 `/etc/ld.so.conf.d/ax650.conf`：

```bash
echo "/soc/lib" | sudo tee /etc/ld.so.conf.d/ax650.conf
sudo ldconfig
```
